# Disertation Project - Chorepad

### A repo for my dissertation project ChorePad.

This website was created to be self-hosted with a MongoDB database that allows seamless user connections and signups.

Preliminary, the design of the project was based off this figma design file: https://www.figma.com/design/eO1pXeM0RZDBZ0J5Dd8d6k/Dissertation-Design?node-id=15-116

### As this was a dissertation project it is no longer under development and for the time-being is abandonned, however I may pick it up again at some point.
